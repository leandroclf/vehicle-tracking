# Pasta de Configuração

Esta pasta contém arquivos de configuração e referência do projeto.

## Arquivos

- `requirements.txt` - Lista de referência das principais dependências do projeto
  - Este arquivo serve como documentação das dependências utilizadas
  - A instalação real das dependências é feita via `npm install` usando o `package.json`

## Organização

Arquivos de configuração específicos que não precisam estar na raiz do projeto são organizados aqui para manter a estrutura limpa e organizada.
